# stroke-predictor
A machine learning model that predicts the possibility of a stroke given various factors.

## Dataset (.csv file)
The dataset used was the [Stroke Prediction Dataset from Kaggle](https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset).\
<br>
Due to licensing restrictions, in order to use this model, you will need to download the dataset yourself. Once downloaded, create a folder called "_data_" and place the .csv file inside.
